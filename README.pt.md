## <img src="https://github.com/KrishBharadwaj5678/ARimals/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Baixe as imagens

- **Baixe as imagens dos animais** da pasta `markers` do repositório para o seu dispositivo.

### 2️⃣ Baixe o aplicativo

- [Baixe o aplicativo](https://drive.google.com/file/d/1djb-FUEnDeQPxxXT_m3Vcit2pRl-SKKc/view?usp=sharing) usando o link fornecido no repositório.

### 3️⃣ Inicie o aplicativo

- **Abra o aplicativo** para começar a experiência imersiva de realidade aumentada.

### 4️⃣ Digitalize a imagem

- **Digitalize qualquer imagem baixada** usando o aplicativo para ativar a experiência de AR.

### 5️⃣ Explore em AR

- **Explore animais 3D realistas** diretamente na tela do seu dispositivo.
