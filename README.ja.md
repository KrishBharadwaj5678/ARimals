## <img src="https://github.com/KrishBharadwaj5678/ARimals/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ 画像をダウンロード

- **動物の画像をダウンロード**し、リポジトリの `markers` フォルダからお使いのデバイスに保存してください。

### 2️⃣ アプリをダウンロード

- リポジトリに記載されているリンクから[アプリをダウンロード](https://drive.google.com/file/d/1djb-FUEnDeQPxxXT_m3Vcit2pRl-SKKc/view?usp=sharing)してください。

### 3️⃣ アプリを起動

- **アプリを開いて**、臨場感あふれるAR体験を始めましょう。

### 4️⃣ 画像をスキャン

- **ダウンロードした画像をアプリでスキャン**すると、AR体験が開始されます。

### 5️⃣ ARで体験

- **リアルな3D動物を画面上で楽しみながら探索**できます。
