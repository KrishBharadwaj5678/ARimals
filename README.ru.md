## <img src="https://github.com/KrishBharadwaj5678/ARimals/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Скачайте изображения

- **Скачайте изображения животных** из папки `markers` репозитория на своё устройство.

### 2️⃣ Скачайте приложение

- [Скачать приложение](https://drive.google.com/file/d/1djb-FUEnDeQPxxXT_m3Vcit2pRl-SKKc/view?usp=sharing) можно по ссылке, указанной в репозитории.

### 3️⃣ Запустите приложение

- **Откройте приложение**, чтобы начать захватывающее дополненное AR-окружение.

### 4️⃣ Отсканируйте изображение

- **Отсканируйте любое скачанное изображение** с помощью приложения, чтобы активировать AR-опыт.

### 5️⃣ Исследуйте в AR

- **Исследуйте реалистичных 3D-животных** прямо на экране своего устройства.
